# Novita CLI (nv)

Reference for the Novita CLI (`nv`). Each command has its own page:

- [account](account.md) — Show the account's Novita balance and credit.
- [api](api.md) — Raw namespaced call over nv's own transport.
- [auth](auth.md) — Manage Novita API credentials in a stable per-user store.
- [billing](billing.md) — Query Novita bills: monthly, usage, fixed-term, and more.
- [catalog](catalog.md) — Public catalog: GPU products per category, and regions.
- [cluster](cluster.md) — Clusters: Novita's datacentre catalog (read-only).
- [doc](doc.md) — Read the manual embedded in nv's own source comments.
- [pod](pod.md) — GPU instance lifecycle ("pods").
- [registry](registry.md) — Container-registry auths: credentials Novita uses to pull private images.
- [serverless](serverless.md) — Serverless GPU endpoints (BYO-container).
- [template](template.md) — Templates: reusable instance configuration snapshots.
- [upgrade](upgrade.md) — Update nv in place from the latest GitHub release.
- [volume](volume.md) — Network storage: durable volumes mountable by instances and endpoints.
